## 朝5時のランニングコースで思うこと

朝5時にランニングシューズを履いて走りに出ると、必ず同じ疑問が浮かぶ：

**「この習慣を続けるには、何が必要か？」**

単なる意志力ではない。朝ランを6ヶ月続ける人と、3週間で挫折する人の差は何か？

それは、**「習慣の本質を理解しているか」** という一点に集約される。

そして、その理解を深める書籍が、確実に存在する。

---

## 経営層向け必読書5冊

### 1. 『習慣のちから』（チャールズ・デュヒッグ）

**朝ランを続けるなら、これは必読。**

この本が教えてくれるのは、習慣は「意志力」ではなく「ループ」で成り立つということ。

```
キュー（引き金）→ ルーティン（行動）→ リワード（報酬）
```

朝5時のランニングも、この論理で成り立っている：

- **キュー**：朝4:50のアラーム音
- **ルーティン**：起床→シューズを履く→走る
- **リワード**：朝日を見る爽快感＋脳のセロトニン分泌

この本を読むと、「意志力で朝ランを続けようとしていた自分は何をしていたのか」という気づきが得られる。

**企業リーダーにとってのポイント：** 
チームに習慣を定着させるなら、強制ではなく「ループの設計」を考えることが重要。

**関連記事：** [朝ランの習慣化が難しい理由と、3週間で定着させる実装ガイド](/posts/habit-formation-morning-run-3weeks/)

**Amazonで詳細を見る →** [習慣のちから](https://amzn.asia/d/7K7w3zH)

---

### 2. 『Getting Things Done』（デイビッド・アレン）

**判断力が低下する午後3時以降。この本が解決策を示す。**

GTDは、単なる「タスク管理術」ではなく、**「思考を外部化する方法」** だ。

朝ランで消費される体力・脳力、それから夜まで続く意思決定の数。多くの経営層は、この「認知的過負荷」に気づいていない。

GTDの本質は：

```
「頭は、タスクを『記憶』する器ではなく、『考える』器」
```

つまり：
- タスクはすべて外部に記録する
- その結果、脳は「判断」に集中できる

朝ランを続けながら、夜の会議で正確な判断ができるのは、このシステムのおかげ。

**企業リーダーにとってのポイント：**
判断力の維持＝認知負荷の最小化。チーム全体にGTDを導入すれば、会議の質が上がる。

**Amazonで詳細を見る →** [Getting Things Done](https://amzn.asia/d/6fpGVqV)

---

### 3. 『7つの習慣』（スティーヴン・R・コヴィー）

**朝ランの先にある「人生設計」を教えてくれる本。**

この本の第1習慣「主体性を発揮する」は、朝ランの本質そのもの。

```
刺激（朝の誘惑：あたたかい布団）
　　↓
反応（選択肢1：布団の中にいる / 選択肢2：走りに出る）
　　↓
判断（自分の人生で何が重要か）
```

朝ランを選ぶ人は、無意識にこの思考プロセスを実行している。

そしてコヴィーはさらに教えてくれる：「この主体性の発揮が、全ての成功の基盤」だと。

**企業リーダーにとってのポイント：**
組織全体が「反応的」になっていないか。主体的な行動文化を作るには、リーダー自身が朝ランのような「主体的な選択」を、毎日可視化する必要がある。

**Amazonで詳細を見る →** [7つの習慣](https://amzn.asia/d/1uZXAZY)

---

### 4. 『戦略的思考とは何か』（楠木建）

**「なぜ朝ランを続けるのか」の戦略的な理由が書かれている。**

多くの経営層は「朝ランは健康に良い」という理由で走っている。

しかし、本当の理由は？

楠木建のこの本が提示するのは、「戦略とは、制約の中での選択」という考え方。

朝ランも同じ：

```
制約：24時間は有限
選択肢：仕事に時間を使うか / 健康に時間を使うか / 判断力を鍛えるか

戦略的選択：朝ランで、3つ全てを実現する
```

この本を読むと、朝ランは「単なる運動」ではなく、「経営判断の先読み投資」であることに気づく。

**企業リーダーにとってのポイント：**
短期利益と長期成長のバランス。朝ランの30分は「短期的には時間損失」に見えるが、判断力向上による長期利益を考えると、最も効率的な投資。

**Amazonで詳細を見る →** [戦略的思考とは何か](https://amzn.asia/d/5J2xCzB)

---

### 5. 『イノベーションのジレンマ』（クレイトン・M・クリステンセン）

**朝ランのような「小さな習慣」が組織を変える仕組みが書かれている。**

破壊的イノベーションの本質は「小さく始める」ということ。

朝ランも同じロジック：

```
新しい習慣（朝ラン）
　　↓
パフォーマンス向上（判断力向上）
　　↓
チーム全体への波及
　　↓
組織文化の変化
```

多くの経営層は「組織変革」を大規模プロジェクトで実現しようとする。

しかし、最も効果的な変革は「朝ラン」のような小さな習慣から始まる。

**企業リーダーにとってのポイント：**
自分が朝ランを続けることで、チーム内に「判断力重視の文化」が自然に広がる。これが本当のイノベーション。

**Amazonで詳細を見る →** [イノベーションのジレンマ](https://amzn.asia/d/2FxSvQ8)

## これらの本をどう読むか？

### 読書の最適なタイミング

```
移動時間：『習慣のちから』『7つの習慣』（概念理解）
朝ランの後：『Getting Things Done』『戦略的思考とは何か』（実装的な読書）
週末：『イノベーションのジレンマ』（全体像の把握）
```

### 実装ガイド：読んだ後、何をするか

```
Week 1：『習慣のちから』を読み、自分の朝ランループを分析
Week 2：『Getting Things Done』を読み、タスク管理システムを構築
Week 3：『7つの習慣』を読み、人生目標を再定義
Week 4：『戦略的思考とは何か』『イノベーションのジレンマ』を読み、組織への適用を考える
```

## 朝ランと読書は、セットで機能する

朝5時のランニングコースで、脳は最も創造的な状態になっている。

その時に、これら5冊で得た「概念」が、無意識に処理される。

結果として：

- 習慣が定着する
- 判断力が向上する
- 組織が変わる

これが、エグゼクティブランナーが読むべき書籍の本質だ。
