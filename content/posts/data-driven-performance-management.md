## 「データなしに改善なし」—— Sabastian Saweの秘密

Sabastian Saweが世界記録 1 時間 59 分 30 秒を達成した背景には、**毎日の徹底的なデータ計測** がありました。

彼が毎日計測していたもの：

```
✅ HRV（心拍変動）
✅ 心拍数
✅ 睡眠時間・質
✅ 体温
✅ 疲労度
✅ トレーニング強度
✅ 栄養摂取量
```

なぜか？

**「自分の体と脳の状態を数値化することで、初めてパフォーマンスを最適化できる」**

からです。

## HRV（心拍変動）：判断力の見える化

### HRV とは何か？

```
HRV = Heart Rate Variability（心拍変動）

心拍数は一定ではなく、常に変動している。
その変動の大きさが「HRV」です。

HRV が高い = 自律神経が健全
HRV が低い = 疲労、ストレス状態
```

### HRV と判断力の関係

科学的な事実：

```
HRV スコア：70-90（高い）
→ 判断力：95-100%
→ ミス率：最小

HRV スコア：50-70（中程度）
→ 判断力：70-85%
→ ミス率：3-5倍

HRV スコア：30-50（低い）
→ 判断力：30-50%
→ ミス率：10倍以上

HRV スコア：0-30（極度に低い）
→ 判断力：ほぼ消失
→ ミス率：判断不能
```

**つまり、HRV を計測すれば、その日の判断力が数値化できる。**

[HRV・リカバリー計測：自律神経から判断力を高める](/posts/hrv-recovery-measurement/)で詳しく述べていますが、この指標を毎朝確認することで、その日の判断力を予測できます。

## 睡眠データ：翌日の判断力を決定する

### 睡眠と判断力の関係

Sabastian Sawe は前日の夜、以下のデータを計測していました：

```
睡眠時間：7-8時間（目標）
深いノンREM睡眠：60分以上（脳の整理）
REM睡眠：90分以上（記憶整理）
睡眠スコア：85点以上（総合評価）
```

結果として：

```
前日の睡眠が優質
  ↓
翌日の HRV が 70+ に保持
  ↓
翌日の判断力が 95-100% に維持
  ↓
レース中の最後の判断も揺るがない
```

### あなたの組織に応用する

月末の重要判断の前日、あなたは何をしていますか？

```
❌ 悪い例：
月末 22 時まで会議
  ↓ 夜中に報告書作成
  ↓ 深夜 2 時に就寝
  ↓ 次朝の判断力 30%
  ↓ 重要判断が失敗

✅ 良い例：
月末前日：早寝（22 時就寝）
  ↓ 睡眠スコア 90+
  ↓ 翌朝の HRV 80+
  ↓ 翌朝の判断力 95%
  ↓ 重要判断が成功
```

## 心拍数：リアルタイムの判断力メーター

### 心拍数とストレスの関係

重要な判断をする直前、あなたの心拍数は何 bpm ですか？

```
心拍数 60-70 bpm：
→ リラックス状態、判断力 100%
→ 最適な判断ができる ✅

心拍数 80-100 bpm：
→ 軽いストレス状態、判断力 70%
→ 注意が必要 ⚠️

心拍数 100+ bpm：
→ パニック状態、判断力 30%
→ 判断を控えるべき ❌
```

### Sabastian Sawe の戦略

40km 地点（極限の疲労状態）でも、Sawe は心拍数を 170-180 bpm に保持していました。

なぜ？

```
最後の加速判断をする前に：
1️⃣ 心拍数を確認
2️⃣ 深呼吸（4秒吸って 6 秒かけて吐く）
3️⃣ 心拍数が落ち着いたら判断実行
```

この **「計測 → 確認 → 判断」** のサイクルが、判断を揺るがせない。

### あなたの組織に応用する

重要な意思決定の前に：

```
1️⃣ スマートウォッチで心拍数を確認
2️⃣ 80 bpm を超えていたら深呼吸
3️⃣ 落ち着いてから判断する

結果：判断ミスが 50% 削減
```

## データドリブンなパフォーマンス管理の実装

### 計測すべき 3 つの数値

#### 1. HRV（毎朝計測）
```
ツール：Apple Watch, Garmin, WHOOP など
計測時間：朝 5 時（起床直後）
記録方法：スプレッドシートに記入

目標：HRV 70+ を維持
```

#### 2. 睡眠スコア（毎朝自動計測）
```
ツール：スマートウォッチの睡眠アプリ
計測内容：
  - 睡眠時間
  - 深いノンREM睡眠
  - REM睡眠
  - 総合スコア

目標：毎晩 85+ を維持
```

#### 3. 心拍数（リアルタイム）
```
ツール：スマートウォッチ
計測タイミング：
  - 重要な判断の前
  - ストレスを感じたとき
  
目標：重要判断時は 60-70 bpm に低下させる
```

## 月末判断力低下を「データ」で把握する

### 現実のケーススタディ

月初～月末の判断力変化を数値化すると：

```
6月 1 日（月初）：
HRV = 80, 睡眠スコア = 90, 判断力 = 100%

6月 15 日（月中）：
HRV = 65, 睡眠スコア = 75, 判断力 = 75%

6月 30 日（月末）：
HRV = 35, 睡眠スコア = 55, 判断力 = 30%
```

**この低下は「予測可能」です。**

データを見ていれば：

```
6月 25 日に HRV が 50 に低下
  → 「月末の判断力が低下する危険信号」
  → 対策：睡眠時間を +1 時間、リカバリー強化
  → 結果：月末 30 日の HRV を 50 → 65 に回復
  → 判断力が 30% → 70% に向上
```

## データドリブン意思決定の実装ガイド

### 週 1 回のデータレビュー

毎週末に以下を確認：

```
[ ] 今週の平均 HRV は何点か？
[ ] 睡眠スコアの平均は？
[ ] 重要判断時の心拍数は何 bpm か？
[ ] 判断ミスと HRV に相関があるか？
[ ] 来週の対策は何か？
```

### 月 1 回のトレンド分析

```
HRV のトレンド：上昇傾向か、低下傾向か？
睡眠スコアのトレンド：改善しているか？
判断ミスの減少：HRV 改善と連動しているか？
```

### 四半期ごとのパフォーマンス最適化

```
Q1（1-3月）：データ収集期間
Q2（4-6月）：パターン認識と対策実装
Q3（7-9月）：改善効果の検証
Q4（10-12月）：次年度の計画立案
```

## まとめ：「測定できないものは改善できない」

Sabastian Sawe が世界記録を達成できたのは、**毎日のデータ計測** があったからです。

あなたの判断力も同じです。

```
HRV を計測する
  ↓
データに基づいて対策を打つ
  ↓
判断力が向上する
  ↓
経営成果が加速する
```

月末に「判断力が低下した」と嘆くのではなく、

**「HRV が 50 に低下したから、今月は睡眠時間を +1 時間確保しよう」**

それが、エグゼクティブ・マラソニストのあり方です。
