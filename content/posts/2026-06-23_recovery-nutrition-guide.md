## マラソン完走後、判断力が消える理由

42.195km を走ると、体に何が起こるか？

```
エネルギー消費：約 2,500kcal
筋肉ダメージ：繊維の 30% が微細破断
脳糖質枯渇：グリコーゲンが 70% 減少
電解質喪失：ナトリウム・カリウム・マグネシウムが激減
```

その結果：

```
身体的疲労：+++
判断力低下：50-70%
意思決定能力：ほぼゼロ
```

マラソン完走後、あなたが「何も判断できない」状態になるのは、ランナーズハイではなく、**栄養枯渇による脳機能低下** だ。

この記事では、完走後 72 時間で判断力を 100% に復帰させる栄養戦略を、実装的に解説する。

---

## リカバリー栄養戦略：0-24 時間（完走直後）

### 目標：急速なエネルギー補給

完走直後の 1-2 時間が、リカバリーの勝負どころ。

**Amazonで購入 →** [プロテイン（ホエイプロテイン）](https://www.amazon.co.jp/s?k=ホエイプロテイン&tag=executivemara-22)

### 実装ステップ

```
完走直後（0 分）：
- ポカリスエット 500ml を 15 分かけて飲む
- （脱水と電解質喪失に対応）

完走後 30 分：
- バナナ 2 本 + ヨーグルト 200g
- （急速な糖質補給）

完走後 1 時間：
- プロテインシェイク 1 杯（タンパク質 25g）
- （筋肉の修復開始）
```

### 栄養成分の目標

```
完走直後 2 時間での栄養補給目標：
- 炭水化物：300g
- タンパク質：30g
- 電解質：ナトリウム 500mg、カリウム 500mg
```

## リカバリー栄養戦略：48-72 時間（リカバリー後期）

### 目標：判断力の復帰

この 24 時間で、あなたの判断力は徐々に戻り始める。

栄養補給から「通常食」へのシフトが重要。

### 栄養補給食の活用

**Amazonで購入 →** [リカバリードリンク](https://www.amazon.co.jp/s?k=スポーツドリンク+リカバリー&tag=executivemara-22)

### 実装ガイド

```
朝食（48-54 時間後）：
- タンパク質：25g 以上（卵、チーズ、ハム）
- 炭水化物：60g（ご飯またはパン）

昼食（54-60 時間後）：
- タンパク質：40g 以上（魚、肉、豆）
- 野菜：200g 以上（ビタミン・ミネラル補給）

夜食（60-72 時間後）：
- マグネシウム：再度 400mg 補給
- タンパク質：25g
- 睡眠：8 時間以上
```
