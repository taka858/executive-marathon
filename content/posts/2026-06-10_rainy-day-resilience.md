## 梅雨時期に CEO が「雨の中で走る」理由

6月の梅雨時期。

多くの CEO が考える：

**「雨だから朝ラン やめとこう」**

その判断は、実は **チーム全体を蝕む**。

なぜか？

```
CEO が「雨だから走らない」と判断
  ↓
チーム全体が「雨だから判断を延期」を許容
  ↓
重要な月末判断が雨の日に延びる
  ↓
判断力が低い状態で重要決定
  ↓
失敗
```

一方、**雨の中でも朝ラン を続ける CEO** は：

```
「雨でも走る」という判断を毎日実行
  ↓
チーム全体が「困難な中でも続ける」を学ぶ
  ↓
月末判断が来ても「雨でも走る CEO がいるから」と踏ん張る
  ↓
チーム全体の判断品質が向上
```

**リーダーの「雨の日の選択」が、チーム文化を作る。**

## 梅雨時期は判断力が 30% 低下する

気象学的な事実：

```
梅雨時期の特徴：
- 気圧低下：酸素濃度低下
  → 脳への酸素供給 -15%
  → 判断力低下
  
- 湿度上昇：90%+
  → 睡眠の質低下
  → HRV 低下
  
- 日照時間減少：
  → セロトニン低下
  → メンタル低下
  
結果：
梅雨時期の判断力 = 通常時の 70%
```

つまり、梅雨時期に重要判断をするなら、**「朝ランで判断力を +20% 回復させる」が必須** なんです。

## 雨の中で朝ラン を続ける CEO：5つの工夫

### 1️⃣ **防水ギアへの投資（これだけで 80% 解決）**

```
❌ 悪い例：
「雨だから走れない」
→ 雨具がない、靴が濡れる、気持ちが萎える

✅ 良い例：
防水ジャケット + 防水シューズ + 防水バッグ
→ 「濡れることへの不安」がなくなる
→ 走ることだけに集中できる
```

**実装：Amazon で「防水ランニングジャケット」を一つ買う。**

コスト：¥5,000-8,000
効果：梅雨時期の走行継続率 +70%

### 2️⃣ **「雨ラン」を特別扱いにしない（心理学的トリック）**

```
❌ 悪い例：
「今日は雨だから、頑張ろう」
→ 心理的負荷が高い
→ 続かない

✅ 良い例：
「今日も走ろう」
→ 「雨」という情報を排除
→ 自然に続く
```

**チーム内での発言例：**
```
「雨ですね」と言われたときの返答：

❌ 「雨だけど走ってきた」（頑張ってますアピール）
✅ 「朝ラン してきた」（自然な報告）
```

相手に「雨での頑張り」を感じさせない。自然にやってる感を出す。**これが心理学的には最高。**

### 3️⃣ **「雨の朝ラン」の報酬を明確化**

```
走った後の楽しみを作る：

朝ラン後 → シャワー → 
 ↓
「雨の中でも走れた」という小さな達成感 + 
「好物の朝食」という物理的報酬
 ↓
脳が「雨の朝ラン = 気持ちいい」と学習
```

**具体例：**
```
月：朝ランの後、好物のコーヒーを飲む
火：朝ランの後、好物のパンを食べる
水：朝ランの後、好物のヨーグルトを食べる
...

「雨の中で走る = 報酬がもらえる」という脳の学習
```

### 4️⃣ **チーム内での「小さな発表」**

```
朝礼で 10 秒間：
「今朝も雨の中、朝ラン してきました」

効果：
- CEO が「雨でも走る」姿勢を見せる
- チームが「困難な中でも続ける」を学ぶ
- 他のチームメンバーが「自分も頑張ろう」と思う
- チーム全体のレジリエンスが向上
```

**ポイント：**
- 「雨での頑張り」をアピールしない
- 「朝ランを続けてる」という事実だけを伝える
- さらりと、自然に

### 5️⃣ **「梅雨時期は判断力が低下する」をチーム内で共有**

```
朝礼で一度、説明する：

「梅雨時期は気圧低下で判断力が 30% 低下します。
だからこそ、朝ラン で判断力を回復させています。
みなさんも、自分の判断力を意識して、
月末判断には自分の回復時間を作ってください」

効果：
- チームが「梅雨時期の判断力低下」を認識
- CEO が朝ランを続ける理由が理解される
- チーム全体で「判断力マネジメント」が始まる
```
