## 朝4時半、暗闇の中で判断力を鍛える

朝4時半に起床してランニングコースに出ると、街はまだ真っ暗だ。

この暗闇の中で走ることの価値は、単なる「運動」ではない。**予測不可能な環境での判断力を鍛える** ことだ。

しかし、暗闇で走るには、適切な装備が必須だ。

この記事では、経営層向けに、朝4時半のランニングで本当に必要な5つの装備を、実装的に紹介する。

## 実装ガイド：朝4時半ランナーのチェックリスト

```
走行前（前夜に確認）：
[ ] シューズの紐を確認
[ ] ウォッチのバッテリー確認（最低 50%）
[ ] ライトのバッテリー確認
[ ] ウェアが洗濯済みか確認
[ ] 補給食をウエストポーチに入れた

走行中：
[ ] 最初の 5 分で足の感覚を確認
[ ] ライトが点灯しているか確認
[ ] 呼吸のリズムが整っているか確認
[ ] 20 分ごとに心拍数をチェック

走行後：
[ ] ウォッチのデータを記録
[ ] シューズを乾燥
[ ] ウェアを洗濯
```
